@ltron/deepfield

A zoomable WebGL2 map for any hierarchy.

Scroll (or pinch) to dive from roots, through branches, down to individual leaves — with a continuous cross-fade between levels instead of discrete drill-down clicks. Zero runtime dependencies. ~30 kB minified. Renders 10k+ nodes on the GPU.

How it works

Semantic-zoom bands

Every node declares s_min / s_opt / s_max — the zoom range it's worth showing. The GPU cross-fades discs in and out through a smoothstep trapezoid every frame, so there's no viewport fetching and no scene graph: the whole map uploads once and the shader decides what's visible.

Deterministic layout

No RNG, fixed iteration counts, sorted children. layout() sizes siblings by weight (area-proportional radius) and places them by PCA-projected similarity when you supply embeddings — otherwise a golden-angle spiral. The same input always produces the same map.

Two ways in

Hand over a hierarchy and let the browser compute geometry:

const data = layout(roots, { weight: n => n.size });
new Deepfield(el, { data });

…or skip layout() and ship precomputed geometry from your backend:

new Deepfield(el, {
  data: await fetch("/map").then(r => r.json()),
});

Zero dependencies

ESM, CJS and a plain IIFE build, no bundler required — <script src="deepfield.global.js"> defines window.Deepfield and just works.
